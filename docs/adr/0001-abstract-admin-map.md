# 地图用自绘行政区，不接真实地图 SDK

## 背景

v1 只需要把 Meal 聚合到省级行政区（着色）与地级市（气泡），不需要街道级底图，也不需要 GPS 定位。

## 决定

地图使用内置的省级 GeoJSON + 城市坐标，在 Canvas 上自绘；不接入高德/腾讯等真实地图 SDK。

## 考虑的方案

- **真实地图 SDK**：有真实瓦片与定位，但需要 API key、开发者实名、隐私合规声明，且依赖网络。
- **自绘行政区**（选中）：完全离线、无 key、无合规负担；视觉上更像"美食足迹图"。代价是失去底图细节与精确定位。

## 后果

- GeoJSON 与城市数据集随 App 打包，需控制体积（预计几百 KB）。
- 若未来要做街道级交互或真实底图，需整体替换渲染层，并重新评估合规成本。
