# 用城市点阵代替行政区边界

## 背景

产品需要一张能让人认出「中国」的地图，用来展示吃过的城市分布。最初方案（ADR-0001）是自绘省级行政区 GeoJSON。但《地图管理条例》要求向社会公开的地图送审，个人开发者无法提供第 16 条要求的测绘资质证书；标准地图虽可免送审，但简化几何、交互缩放都属于「编辑」，需重新送审。即使改用许可干净的 Natural Earth，其边界表述与中国主张不一致，在国内发布属于「问题地图」。

## 决定

**不绘制任何行政区域界线或疆域轮廓**。地图由三类点构成：

- **城市点**（约 372 个地级市）：可交互，按 Meal 数量改变大小与颜色。
- **区县点**（约 2851 个）：仅作为背景点填充轮廓，不标注、不可点。
- **省份不渲染为面**，只作为聚合维度出现在图例与统计中。

坐标取自 AreaCity（MIT 声明，GCJ-02），只保留名称、隶属与中心点，剔除全部 polygon 字段。

## 考虑的方案

- **省级多边形**（原方案）：视觉最接近「足迹地图」，但需要审图号或承担合规风险；且要发布到中国区应用商店时风险更高。
- **真实地图 SDK**：同样受审图约束，另加 API key、实名与隐私合规。
- **点阵**（选中）：不表示疆域与界线，规避地图审核；轮廓由 3000 多个真实点位自然勾勒，视觉上仍可辨认。

## 后果

- 「省份着色」这个交互不存在了；省份只能以图例/统计形式出现。
- 轮廓清晰度取决于点的密度：西部点位稀疏，边界感弱于真实地图。若需要更清晰的轮廓，**只能增加点位（如乡镇级）**，不能改为画线。
- 数据体积约 133KB，可完全离线。
- 数据的上游权利存在瑕疵（采集自高德/腾讯/国家地名信息库），已在 `assets/data/NOTICE.md` 注明来源与坐标系；若商业发行需替换为有明确授权的数据源。
