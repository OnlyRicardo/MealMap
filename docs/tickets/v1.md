# v1 工单（tracer bullet）

每个工单都是一条可验证的纵向切片，完成后 App 处于可运行状态。`→` 表示阻塞边（左侧完成后右侧才能开始）。

## T1 项目骨架
`flutter create`、依赖（drift / sqlite3_flutter_libs / path_provider / image_picker / share_plus / file_picker / uuid / intl）、lint 规则、目录分层（`app/ domain/ data/ features/`）。
**验收**：`flutter analyze` 干净，空首页能在模拟器启动。

## T2 数据层与迁移
drift 表结构（§2）、schema 导出、`MealRepository` 接口与实现、级联删除。
**验收**：单测覆盖 CRUD、删 Meal 级联删 Dish/Photo/Tag 关联、菜系被引用时不可删除只能归档。

## T3 内置数据集
菜系种子（§3）、省市数据集（含坐标）、省级 GeoJSON（简化到体积预算内）、加载与聚合查询。
**验收**：给定若干 Meal，能算出「省份 → 数量」「城市 → 数量」；GeoJSON 体积 ≤ 预算；解析耗时 ≤ 100ms。

## T4 记一餐表单
日期、餐次（可空）、城市选择器（省→市 + 常用城市）、菜系单选、菜品多行、标签、备注。
**验收**：标签 2–12 字、单餐 ≤10 个、同名复用；必填校验；保存后出现在当日。

## T5 照片管线
多选（≤9）、压缩（长边 2048 / q80）、缩略图（200px）、私有目录、文件命名与删除。
**验收**：选 9 张后第 10 张不可选；删除 Meal 后文件与缩略图均消失；列表按目标尺寸解码。

## T6 美食地图
CustomPainter 绘制省级多边形 + 城市气泡、数量着色与图例、年份切换、点击省份下钻。
**验收**：golden 测试固定 3 组数据；切换年份后聚合正确；1 万条 Meal 下重绘 ≤ 16ms（预投影 + 缓存 Path）。

## T7 美食日历
月视图（缩略图/菜系色点）、当天弹层、年视图只读热力图。
**验收**：golden 测试；跨月翻页正确；年视图点击无响应（只读）。

## T8 详情 / 编辑 / 删除
从日历当天弹层进入，编辑全字段，删除二次确认。
**验收**：修改菜系后地图与统计同步变化。

## T9 设置
菜系管理（新增/改名/归档）、标签管理（重命名/合并/删除）、关于页。
**验收**：归档菜系不再出现在选择器，但历史 Meal 显示原名。

## T10 导出 / 导入 / 一键移机
`data.json`(带 format_version) + photos/ + thumbs/ 打 zip、系统分享、导入校验与事务写入、冲突跳过计数。
**验收**：spec §9 第 5 条全流程通过；版本不兼容时报错且不写入半份数据。

## T11 发布前打磨
release 移除 INTERNET 权限、空状态与错误态、启动性能、README/截图、LICENSE 确认。
**验收**：飞行模式下 spec §9 全部通过；APK 可直接安装。

## 依赖关系

```
T1 → T2 → T3 → T6 → T8
        ├ → T4 → T5 → T9
        └ → T10
T6/T7 可并行；T10 依赖 T5；
```
